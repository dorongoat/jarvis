# ג'ארוויס

עוזר קולי דו-לשוני (עברית ואנגלית) לווינדוס, בהשראת ג'ארוויס של איירון מן: מילת הפעלה, קול טבעי,
ממשק HUD עם כור קשת מונפש, שליטה אמיתית במחשב ומודל שפה מקומי - הכול נשאר אצלך במחשב.

![ממשק ג'ארוויס](assets/hud.png)

## מה הוא יודע לעשות

- **מילת הפעלה** - אומרים "ג'ארוויס" (או "Jarvis") ומדברים. הוא נשאר ער לשיחת המשך וחוזר להמתנה לבד.
- **שתי שפות** - מזהה ועונה בעברית או באנגלית, לפי השפה שבה דיברת, כולל מעבר באמצע שיחה.
- **קול טבעי** - קולות נוירונים של מיקרוסופט (`he-IL-AvriNeural`) בחינם וללא מפתח, עם נפילה לקולות ווינדוס במצב לא מקוון.
- **מוח** - מודל מקומי וחינמי דרך [Ollama](https://ollama.com), או OpenAI / Anthropic אם מעדיפים.
- **שליטה במחשב** - פתיחת תוכנות ואתרים, חיפוש בגוגל וביוטיוב, עוצמת קול, צילום מסך, נעילה/כיבוי/אתחול,
  מצב מערכת, פתקים, טיימרים, מזג אוויר, שעה ותאריך.
- **HUD** - חלון PyQt6 עם כור קשת מונפש שמגיב למצב, יומן שיחה עם תמיכה מלאה ב-RTL ותיבת טקסט
  למקרים שאי אפשר לדבר.

## התקנה (ווינדוס)

```powershell
git clone <כתובת המאגר> jarvis
cd jarvis
powershell -ExecutionPolicy Bypass -File install_windows.ps1
```

הסקריפט יוצר סביבה וירטואלית, מתקין את כל התלויות, יוצר `config.yaml` ומוריד את המודל המקומי
אם Ollama מותקן. להתקנת המודל (נדרש לשיחה חופשית, לא לפקודות):

```powershell
winget install Ollama.Ollama
ollama pull llama3.1:8b
```

הפעלה:

```bat
run_jarvis.bat
```

דגלים שימושיים: `--cli` (ממשק טקסט), `--no-voice` (בלי מיקרופון), `--mute` (בלי דיבור),
`python -m jarvis --list-mics` (רשימת מיקרופונים), `python -m jarvis --say "מה השעה"` (פקודה בודדת).

לקובץ הרצה יחיד: `powershell -ExecutionPolicy Bypass -File build_exe.ps1` ואז `dist\Jarvis\Jarvis.exe`.

## הגדרות

הכול נמצא ב-`config.yaml` (הגרסה המתועדת: `config.example.yaml`): מילות הפעלה, מנוע זיהוי דיבור,
קולות ומהירות דיבור, ספק המודל, קיצורי דרך לתוכנות שלך, עיר למזג אוויר וצבע הממשק.

החלפת מוח היא שורה אחת:

```yaml
brain:
  provider: "openai"   # ollama | openai | anthropic | offline
```

המפתחות נקראים ממשתני הסביבה `OPENAI_API_KEY` / `ANTHROPIC_API_KEY`.

## פתרון תקלות

- **אין מיקרופון / לא שומע אותי** - `python -m jarvis --list-mics` ואז עדכן את `speech_to_text.microphone_index`.
- **מגיב לרעש** - העלה את `speech_to_text.energy_threshold`.
- **אין תשובות בשיחה חופשית** - ודא ש-Ollama רץ (`ollama serve`) ושהמודל הורד.
- **הקול באנגלית במקום בעברית** - ודא ש-`text_to_speech.voice_he` מוגדר ושיש חיבור לאינטרנט
  (מנוע `edge`); אחרת עבור ל-`engine: "sapi"` והתקן קול עברית בהגדרות ווינדוס.
